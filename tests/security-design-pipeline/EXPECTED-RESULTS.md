# Expected Integration Results

## Structural

`security-copilot_v4.skill` is a valid archive containing `SKILL.md` and its seven reference documents.

## Architecture

Design-by-Security produces a threat-driven, testable design model and security gate.

## Operations

Security Copilot receives structured context and performs operational analysis without redefining the architecture contract.

## Feedback

Operational findings can become security debt and drive requirement/control changes and redesign.

## Safety

No destructive production action is autonomous; human approval remains a mandatory control.

## Regression

Changes to either side of the integration contract must be caught by the CI workflow before merge to `main`.
