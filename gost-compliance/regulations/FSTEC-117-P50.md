# Приказ ФСТЭК России №117 — пункт 50

## Normative boundary

For independently developed software intended for use in information systems, пункт 50 requires implementation of measures provided by sections 4 and 5 of ГОСТ Р 56939-2024.

## Repository traceability

```text
FSTEC-117-P50
  → GOST R 56939-2024 §4 General requirements
  → GOST R 56939-2024 §5 Secure software development processes
  → gost-compliance/GOST-MAPPING.yml
  → process artifacts 5.1–5.25
  → gost-compliance/pipeline/gost-validate.sh
```

## Important limitation

This document is a traceability/control boundary. A passing repository validator is evidence that the defined implementation contracts and repository evidence are internally consistent; it is not a legal conclusion that an organization is compliant with the regulation.
